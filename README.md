# Marketing Campaign ROI Analysis (Power BI)

## Overview
This project analyzes marketing campaign data across multiple channels to measure ROI, CAC, LTV, and conversion efficiency.
Includes an A/B test comparison to identify best-performing variants.

### Key Insights
- Identified top ROI channels and campaigns
- Compared A/B test performance to improve conversion rate
- Created Power BI visuals: ROI by Channel, CAC vs LTV, A/B Test Comparison, and KPIs

### Tools
- Microsoft Power BI Desktop
- CSV datasets (for import)
